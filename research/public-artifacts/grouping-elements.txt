resource Build with Canva Apps inside Canva App intents Design Editor Working with elements Grouping elements How to organize elements into groups. Copy page In Canva, a design&#x27;s elements can be organized into groups. The elements in these groups can then be manipulated as a single unit, which is more convenient when working on complex designs. The user experience A group can be moved, resized, rotated, and animated as a single unit. For fine-grained control, users can select and edit any of the individual elements in a group — for example, to apply effects to a specific image. Users have the option of locking a group. When a group is locked, it can&#x27;t be ungrouped, and its elements can&#x27;t be edited. If a group is not locked, it can be ungrouped into its individual elements. What can be grouped? The following types of elements can be organized into groups: Embeds Images Shapes Text Videos The following types of elements cannot be organized into groups: App elements Groups Tables How to create groups Step 1: Enable the required permissions Enable the canva:design:content:write permission with either the Developer Portal or the Canva CLI. In the future, the Canva Developers SDK will throw an error if the required permissions aren&#x27;t enabled. To learn more, see Permissions . Step 2: Add the group to the design Import the addElementAtPoint method (or addElementAtCursor , depending on the current context ) from the @canva/design package: import { addElementAtPoint } from &quot;@canva/design&quot; ; TS Copy Call the method, passing in the options shown here: await addElementAtPoint ( { type : &quot;group&quot; , children : [ { type : &quot;embed&quot; , url : &quot;https://www.youtube.com/watch?v=dQw4w9WgXcQ&quot; , width : 100 , height : 100 , top : 0 , left : 0 , } , { type : &quot;embed&quot; , url : &quot;https://www.youtube.com/watch?v=o-YBDTqX_ZU&quot; , width : 100 , height : 100 , top : 0 , left : 100 , } , ] , } ) ; TS Copy The children property should contain the elements to include in the group. The elements will render in the order they appear — that is, later elements will render in front of earlier elements. Each object in the children array: Must have a width and a height Must have top and left coordinates Can have a rotation , in degrees The one exception is text elements , which don&#x27;t require a width and can&#x27;t have a height . To learn more about how to position elements within a group, see Positioning elements . Known limitations Groups must contain at least two elements. Apps can&#x27;t create locked groups.
