resource Build with Canva Apps inside Canva App intents Design Editor Creating elements Creating text How to add text to a user&#x27;s design. Copy page Text is an essential ingredient in a designer&#x27;s toolkit, and apps can create and otherwise interact with text in a variety of ways. This page explains everything you need to know about working with text. Text formats While using the Canva Developers SDK, text can be represented in either of the following formats: Plaintext Richtext Apps can choose which format to work with, but the choice affects what features are available. Generally speaking, working with plaintext is simpler, while working with richtext is more flexible. Plaintext When creating plaintext, formatting can only be applied to the whole text. When reading plaintext, apps can&#x27;t access the existing formatting information. When updating plaintext, apps can&#x27;t maintain the styling of the text. Richtext When creating richtext, different parts of the text can have different formatting. When reading richtext, apps can access the existing formatting information. When updating richtext, apps can maintain the styling of the text. Text elements Apps can create text elements that contain text content . Users can then control the position, dimensions, and rotation of these containers. Richtext Richtext Plaintext Plaintext To create a richtext element, an app must first create a richtext range. It&#x27;s this range that defines the structure and formatting of the richtext. To learn more, see Richtext ranges . import { addElementAtPoint , createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;Hello world&quot; ) ; await addElementAtPoint ( { type : &quot;richtext&quot; , range , } ) ; TSX Copy import { addElementAtPoint } from &quot;@canva/design&quot; ; await addElementAtPoint ( { type : &quot;text&quot; , children : [ &quot;Hello world&quot; ] , } ) ; TSX Copy Text content When text exists in a design, it&#x27;s known as text content . This content can exist in a variety of containers, including but not limited to: Table cells Text elements It&#x27;s important to understand that &quot;content&quot; is not synonymous with &quot;element&quot;. This distinction matters because some of the features in the Developers SDK operate on content and not on elements (and vice-versa). Text formatting Apps can apply a variety of formatting options to text, including fonts . Richtext Richtext Plaintext Plaintext In the case of richtext, there are two types of formatting: Paragraph formatting Inline formatting Paragraph formatting options can only be applied to entire paragraphs, while inline formatting options can be applied to any range of text, including paragraphs. To learn more, see Formatting richtext . In the case of plaintext, formatting can only be applied to the text as a whole. To view all of the available options, see the API reference . For example, an app could analyze and fix the grammar of the selected text content. Richtext ranges A richtext range is an object that represents a portion of formatted text — anything from a single word to multiple paragraphs — and exposes methods for safely interacting with that range. Before an app creates a richtext element, it must create a range: import { createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; TSX Copy By default, this range does not contain any text. When an app reads existing richtext content, such as when using the Selection API , it receives a range from Canva: const draft = await currentSelection . read ( ) ; for ( const content of draft . contents ) { console . log ( content ) ; // This is the richtext range object } TSX Copy The same methods are available to all ranges, whether or not they were created by the app. There is no concept of a &quot;plaintext range&quot; because plaintext is a simple string that can be modified with standard string manipulation techniques. Creating richtext Apps can create richtext by appending it to a range: import { createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;Hello world.&quot; ) ; TSX Copy This text can be formatted with inline formatting options : import { createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;This is bold.&quot; , { fontWeight : &quot;bold&quot; } ) ; TSX Copy If a formatting option isn&#x27;t specified, its value is inherited from the text that precedes it: import { createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;This is bold. &quot; , { fontWeight : &quot;bold&quot; } ) ; range . appendText ( &quot;This is also bold.&quot; ) ; TSX Copy In other words, when text is appended, formatting options stack on top of one another: import { createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;This is bold. &quot; , { fontWeight : &quot;bold&quot; } ) ; range . appendText ( &quot;This is bold and pink.&quot; , { color : &quot;#ff0099&quot; } ) ; range . appendText ( &quot;This is bold, pink, and italic.&quot; , { fontStyle : &quot;italic&quot; } ) ; TSX Copy Formatting richtext Apps can format text in a variety of ways. A limited range of options are available when formatting inline text. import { addElementAtPoint , createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;This is the first paragraph.\nThis is the second paragraph.&quot; ) ; range . formatText ( { start : 0 , length : 4 } , { fontWeight : &quot;bold&quot; } ) ; TSX Copy All formatting options are available when formatting paragraphs. import { addElementAtPoint , createRichtextRange } from &quot;@canva/design&quot; ; const range = createRichtextRange ( ) ; range . appendText ( &quot;This is the first paragraph.\nThis is the second paragraph.&quot; ) ; range . formatParagraph ( { start : 0 , length : 1 } , { textAlign : &quot;center&quot; } ) ; TSX Copy Be aware that, when formatting paragraphs, any paragraph that overlaps with the specified bounds will be formatted — even if the paragraph only overlaps with a single character. Reading richtext as plaintext Apps can access the plaintext representation of richtext content: import { createRichtextRange } from &quot;@canva/design&quot; ; // Create a richtext range const range = createRichtextRange ( ) ; range . appendText ( &quot;Hello world&quot; ) ; // Get the plaintext representation of the range const plaintext = range . readPlaintext ( ) ; console . log ( plaintext ) ; // =&gt; &quot;Hello world&quot; TSX Copy A common use-case for this behavior is to check if a substring exists before processing the text further: import { createRichtextRange } from &quot;@canva/design&quot; ; // Create a richtext range const range = createRichtextRange ( ) ; range . appendText ( &quot;Hello world&quot; ) ; // Get the plaintext representation of the range const plaintext = range . readPlaintext ( ) ; // Check if the plaintext contains a string if ( plaintext . includes ( &quot;Hello&quot; ) ) { // TODO: Do something here } TSX Copy Reading richtext as text regions Apps can convert a richtext range into an array of text regions . This array allows the app to inspect how formatting is applied to text throughout the range. import { createRichtextRange } from &quot;@canva/design&quot; ; // Create a richtext range const range = createRichtextRange ( ) ; range . appendText ( &quot;Hello world&quot; ) ; // Get an array of text regions const regions = range . readTextRegions ( ) ; console . log ( regions ) ; // =&gt; [{ text: &quot;Hello world&quot; }] TSX Copy Each region represents a distinctly formatted string of characters. For example, each of the following would be represented as a separate region: A string without any explicit formatting. A string with bold formatting. A string with bold and italic formatting. This is demonstrated in the following code snippet: import { createRichtextRange } from &quot;@canva/design&quot; ; // Create a richtext range const range = createRichtextRange ( ) ; range . appendText ( &quot;First text region. &quot; ) ; range . appendText ( &quot;Also the first text region. &quot; ) ; range . appendText ( &quot;Second text region. &quot; , { fontWeight : &quot;bold&quot; } ) ; range . appendText ( &quot;Third text region.&quot; , { fontStyle : &quot;italic&quot; } ) ; // Get an array of text regions const regions = range . readTextRegions ( ) ; console . log ( regions . length ) ; // =&gt; 3 TSX Copy Gotchas Apps can&#x27;t set the line-height of text. Apps can&#x27;t create text with a vertical writing mode. Text elements can&#x27;t have a predefined height. Font sizes are defined with pixels (px) in the API but displayed as points (pt) in the UI.
