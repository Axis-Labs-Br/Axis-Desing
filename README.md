# Axis Desing
AxisDesign é um editor visual open source inspirado no Canva, feito com React, TypeScript e Vite. Permite criar designs, editar múltiplas páginas, importar PDF, DOCX, PPTX e outros formatos, trabalhar com textos, imagens e elementos gráficos, além de exportar para PNG, JPG, SVG, PDF e .axis.
